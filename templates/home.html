System Architecture & Features 🚀

Built with modern Python web standards & local CPU AI inference

🧠

512D ArcFace ONNX AI

Uses optimized local ONNX Runtime model (`w600k_mbf.onnx`) with OpenCV face detection fallback to compute 512-dimensional vector embeddings with >45% cosine match threshold.

🖼️

Multi-Photo Deduplication

Teachers can upload multiple classroom group photos. SCMS analyzes all photos, deduplicates recognized presentees, and provides interactive photo canvas tab switchers.

☁️

Cloudinary Storage

Stores frontal dataset photos under `scms_student_dataset//` and classroom group photos under `scms_classroom_photos/`.

🗄️

Neon PostgreSQL Database

Hosted online database syncing User accounts, Student Roll Numbers, Attendance Sessions, and JSON-encoded 512D embedding vectors safely without local media dependencies.
